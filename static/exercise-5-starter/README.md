# Exercise 5 starter (unpublished)

This credential-free starter is a teaching scaffold, not a working provider.
It records the layout and allowlist contract for Dify 1.16.1 while the local
synthetic gateway and remote-debug runtime remain deferred.

Files:

* `plugin.yaml` – illustrative package metadata;
* `provider.yaml` and `models.yaml` – narrow schema/allowlist examples;
* `provider_stub.py` – deliberately incomplete implementation boundary;
* `test_contract.py` – local checks for aliases and secret-safe errors;
* `requirements.lock` – empty dependency lock for the scaffold; and
* `.env.example` – names only, with no values or origins.

Do not add credentials, private hostnames, customer data, or a solved plugin.
The official provider source pin is recorded in `source-metadata.json`.
